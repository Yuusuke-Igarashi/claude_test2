# 防災コンパス SEA（モック）

東南アジアに拠点を持つ企業・自治体の「リスク管理責任者（管理者）」と「従業員（と家族）」のための防災アプリの試作です。
自己完結の 1 ファイル（`bousai/index.html`）で動き、外部通信をしません。

## 3 つの画面（v2）

想定読者を「行政・企業のリスク管理責任者（管理者）と従業員」に定め、右上の切替で「企業／自治体」（対象グループの種類）と「管理者／従業員」（対策本部向けパネルの表示）を切り替えます。

| # | 画面 | 想定読者 | 構成 |
|---|------|----------|------|
| 1 | 地域・拠点のリスク | 管理者・従業員 | 国・都市 → 拠点 → 対象グループ のツリー。都市：災害別のハザード水準と再現期間別の被害規模。拠点：避難計画・避難所・警報手段・備えスコア。対象グループ：企業は「現地雇用者・家族」「お客様・取引先（サプライチェーン）」、自治体は「地域住民」「支援者・NGO」 |
| 2 | リアルタイムレポーティング | 管理者・従業員 | 国・都市・災害ごとのイベントカード（複数）→ シナリオ時計・時間スライダー・自動再生・フィード受信状況 → 被害全体像／外力状況（降雨・水位・潮位・放流・地震・風としきい値）／被害発生状況（統合フィード）／拠点・サプライチェーン状況 |
| 3 | パーソナライズダッシュボード | 従業員（と家族） | 住所・家族構成・年齢などを入力（住所は登録済みの代表地点にキーワード照合）→ 事前の備え（避難行動・備蓄・行動チェック・家族カード）と、リアルタイム（自宅地区のライフライン・行動指示・天候・連絡先・医療、支援イベント） |

画面 2 の「発災からの経過時間」はイベントごとに保持し、画面 3 のリアルタイム表示と共有します。イベントは 3 件（バンコク大規模洪水、マニラ首都圏直下地震、ジャカルタ大雨・洪水警報＝警戒段階）で、外力の推移・被害の発生・拠点の稼働変化はすべて `data/scenarios.json` のパラメータから生成するデモです。

## データの扱い（重要）

画面上の値は次の 3 種類に分け、ラベルで区別しています。

- **出典付き**（リンク）… ThinkHazard のハザード水準、GEM の地震損失曲線、Natural Earth の地図など。
- **検索要約**… ウェブ検索結果の要約から転記した値。原典ページ本文を取得できていないため、採用前に原典で確認が必要。
- **仮定（デモ）**… 再現期間ごとの影響人口・操業停止・損失、拠点の整備状況、発災シミュレーションのパラメータなど。前提は各画面の「前提と計算方法」に記載。

本セッションの実行環境からは thinkhazard.org・gdacs.org・api.reliefweb.int・data.humdata.org・preventionweb.net・earthquake.usgs.gov・mofa.go.jp・emdat.be・各国防災当局・在外公館のサイトへ直接アクセスできなかった（名前解決不可）ため、これらの値は検索結果の要約、GitHub 上の公開データ（EM-DAT の OWID 集計、Aqueduct の CSV ミラー、OSM／GTFS 由来の座標）、または仮定です。到達できる環境では `data/*.json` を原典で置き換えてください。

### 取得できたもの／できなかったもの

| 区分 | 内容 | 状態 |
|------|------|------|
| GEM 国別地震リスクプロファイル v2026.0.0 | 再現期間 10〜1000 年の建物損失、AAL、再調達価額（9 か国） | 原典画像を取得し転記（CC BY-NC-SA 4.0） |
| WRI Aqueduct Floods（2010 年ベースライン） | 河川洪水の都市被害額（再現期間 10〜1000 年、9 か国） | GitHub 上の CSV ミラーから取得（列の解釈は要検証） |
| EM-DAT（Our World in Data 集計） | 国×年×災害種別の死者・被害額（1900〜2020 年） | GitHub 上の CSV から取得（年間合計値） |
| ThinkHazard! ハザード水準 | 国・州・県の 11 ハザード | 検索結果の要約から転記（原典ページ未取得・要確認） |
| WorldRiskIndex 2025／INFORM 2025 | 国別スコア・順位 | 二次集計サイトの検索要約（要確認）。INFORM は 4 か国のみ |
| 在留邦人数・日系企業拠点数 | 外務省統計 | 未取得（画面では「未取得」と表示） |
| 緊急番号・在外公館・警報チャネル | 各国 | GitHub 上の第三者データからの転記（要確認） |
| 施設座標（病院・公園・駅など） | 4 拠点周辺 | OSM・GTFS・病院リスト等の公開データ（page_read）と未検証の概略が混在。各施設に `coord_src` を付与 |
| 浸水想定域・被害集中域 | 4 拠点周辺 | 公開ハザード図（UP NOAH、GISTDA 集計、GEM 断層トレース）を参考にした近似（仮定） |
| 2021 年以降の災害（台風ヤギ、2025 年ミャンマー地震など） | 死者・被害額 | 概数・未検証（画面では「要確認」タグ） |

## 構成

```
bousai/
  index.html            ビルド済み（自己完結・これだけで動く）
  scripts/build.mjs     src/ と data/ geo/ を 1 ファイルに埋め込む
  src/
    index.template.html 骨組み（アイコン・ヘッダ・組織／閲覧者の切替・3 画面の枠）
    style.css           デザイン体系（ライト／ダーク、地図・図表のトークン）
    core.js             共通処理・ルーター・テーマ・保存
    geo.js              地域図（正距円筒）と拠点周辺の概略図・経路探索
    charts.js           再現期間曲線・棒・時系列
    model.js            再現期間モデル、備えスコア、個人の備蓄計算、発災シミュレーション
    view-risk.js        画面 1：地域 → 拠点 → 対象グループ のツリーと画面遷移
    view-region.js      画面 1：都市（ハザード水準・再現期間別の被害規模・履歴）
    view-site.js        画面 1：拠点（避難計画・避難所・警報・備えスコア）
    view-groups.js      画面 1：対象グループ（現地雇用者・家族／取引先／地域住民／支援者・NGO）
    view-live.js        画面 2：イベント一覧、ライブヘッダ、4 つのタブ、地区単位のリアルタイム情報
    view-personal.js    画面 3：住所の照合、家族の備え、リアルタイム
  data/
    regions.json        地域（都市圏）のハザード水準・履歴・季節性・再現期間モデルの仮定
    sites.json          架空の拠点 4 つと整備状況（仮定）
    areas.json          拠点周辺図：主要道路・水路・施設（公開座標の近似）・浸水想定域（仮定）
    scenarios.json      発災シナリオ（区別の曝露・避難所・物資・ライフライン・タイムライン・外力の推移・被害事象）
    groups.json         拠点ごとの居住分布・取引先・地域住民・支援者（架空・仮定）
    gem.json            GEM 国別地震リスクプロファイル v2026.0.0 から転記した値
    contacts.json       緊急番号・在外公館・警報チャネル
    guidance.json       備えの根拠（内閣府・中小企業庁・外務省・Sphere・WHO など）
    feeds.json          本番版が接続しうる公開フィード
  geo/                  Natural Earth（パブリックドメイン）を東南アジアに切り出し簡略化した GeoJSON
```

ビルド:

```bash
node bousai/scripts/build.mjs
```

## 本番化に向けて

- 地図：OSM タイル／ベクタータイルと現地当局のハザードマップに置き換える
- 発災レポート：GDACS・ReliefWeb・USGS・Copernicus EMS・各国気象／防災当局のフィードを接続する（画面 4 の末尾に一覧）
- 安否確認：既存の安否確認システムと連携し、在留届・たびレジの登録状況を照合する
- 避難所：施設との協定・収容条件・バリアフリー情報を実データ化する
