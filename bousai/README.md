# 防災コンパス SEA（モック）

東南アジアに拠点を持つ企業と、その駐在員家族のための防災アプリの試作です。
自己完結の 1 ファイル（`bousai/index.html`）で動き、外部通信をしません。

## 5 つの画面

| # | 画面 | 想定読者 | 答える問い |
|---|------|----------|------------|
| 1 | 地域リスク（地域版） | 本社リスク管理・海外事業部 | どの災害が、どの頻度で、どの規模の被害をもたらしうるか（再現期間 10〜1000 年） |
| 2 | 拠点の備え（企業・拠点版） | 拠点長・総務・安全管理 | 誰が・どこへ・どの経路で避難し、何を備えるべきか（シナリオ別の最適避難先、警報手段、備えスコア） |
| 3 | 家族の備え（個人版） | 駐在員と家族 | 家族構成・住まいから、避難先・避難路と備蓄量・行動チェック・家族防災カード |
| 4 | 支援者向け 発災レポート | 本社対策本部・支援チーム | 被害の全体像、被災者の分布、支援・物資の需給、次の 24 時間の推奨アクション |
| 5 | 現地向け 発災レポート | 被災地の駐在員・家族・現地対応者 | 電気・水道・通信・交通の復旧、支援イベント、気温と備え、健康・医療、連絡先 |

4・5 はシナリオ（バンコク大規模洪水、マニラ首都圏直下地震）と「発災からの経過時間」を共有し、スライダーで時間を動かすと全パネルが連動します。

## データの扱い（重要）

画面上の値は次の 3 種類に分け、ラベルで区別しています。

- **出典付き**（リンク）… ThinkHazard のハザード水準、GEM の地震損失曲線、Natural Earth の地図など。
- **検索要約**… ウェブ検索結果の要約から転記した値。原典ページ本文を取得できていないため、採用前に原典で確認が必要。
- **仮定（デモ）**… 再現期間ごとの影響人口・操業停止・損失、拠点の整備状況、発災シミュレーションのパラメータなど。前提は各画面の「前提と計算方法」に記載。

本セッションの実行環境からは thinkhazard.org・gdacs.org・reliefweb・HDX・preventionweb・usgs.gov などへ直接アクセスできなかったため、これらの値は検索結果の要約か仮定です。アクセスできる環境では `data/*.json` を原典で置き換えてください。

## 構成

```
bousai/
  index.html            ビルド済み（自己完結・これだけで動く）
  scripts/build.mjs     src/ と data/ geo/ を 1 ファイルに埋め込む
  src/
    index.template.html 骨組み（アイコン・ヘッダ・5 画面の枠）
    style.css           デザイン体系（ライト／ダーク、地図・図表のトークン）
    core.js             共通処理・ルーター・テーマ・保存
    geo.js              地域図（正距円筒）と拠点周辺の概略図・経路探索
    charts.js           再現期間曲線・棒・時系列
    model.js            再現期間モデル、備えスコア、個人の備蓄計算、発災シミュレーション
    view-*.js           各画面
  data/
    regions.json        地域（都市圏）のハザード水準・履歴・季節性・再現期間モデルの仮定
    sites.json          架空の拠点 4 つと整備状況（仮定）
    areas.json          拠点周辺図：主要道路・水路・施設（公開座標の近似）・浸水想定域（仮定）
    scenarios.json      発災シナリオ（区別の曝露・避難所・物資・ライフライン・タイムライン）
    gem.json            GEM 国別地震リスクプロファイル v2026.0.0 から転記した値
    contacts.json       緊急番号・在外公館・警報チャネル
    guidance.json       備えの根拠（内閣府・中小企業庁・外務省・Sphere・WHO など）
    feeds.json          本番版が接続しうる公開フィード
  geo/                  Natural Earth（パブリックドメイン）を東南アジアに切り出し簡略化した GeoJSON
```

ビルド:

```bash
node bousai/scripts/build.mjs
```

## 主な出典

- GFDRR ThinkHazard!（https://thinkhazard.org/）… 州・県レベルのハザード水準
- GEM Foundation, Country/Territory Seismic Risk Profiles v2026.0.0（https://github.com/gem/risk-profiles）… CC BY-NC-SA 4.0（非商用）。商用利用は GEM との個別ライセンスが必要
- Natural Earth（https://www.naturalearthdata.com/）… パブリックドメイン
- World Bank, Thai Flood 2011 Rapid Assessment … 2011 年タイ洪水の被害・損失
- 内閣府 防災情報、中小企業庁 BCP 策定運用指針、外務省 海外安全ホームページ、Sphere Handbook、WHO

## 本番化に向けて

- 地図：OSM タイル／ベクタータイルと現地当局のハザードマップに置き換える
- 発災レポート：GDACS・ReliefWeb・USGS・Copernicus EMS・各国気象／防災当局のフィードを接続する（画面 4 の末尾に一覧）
- 安否確認：既存の安否確認システムと連携し、在留届・たびレジの登録状況を照合する
- 避難所：施設との協定・収容条件・バリアフリー情報を実データ化する
