データ読み込み中

    フォルダ・ファイルを選んで「読み込む」を押してください。1 だけが必須です。
    HTML を出力フォルダに置いて http:// 経由で開いた場合は自動で読み込まれます。

    1. 車流（TomTom 交通統計）のフォルダ（必須）:
    tomtom_out: network.geojson、baseline_/event_ の speed・count CSV、error.csv。または個別に:

    2. 人流（位置ログの前処理結果）のフォルダ（任意）:
    probe_out: viewer/（時刻別ファイル）と grid*/（メッシュ）。徒歩の軌跡と徒歩の増減に使う

    3. 徒歩変化（メッシュ）のフォルダ（任意）:
    walk_mesh.ipynb の grid_walk25（walk25_平時/有事/比率 の GeoTIFF と index.json）。grid_users.py や probe_trips.py の grid/ でも可。徒歩の増減に使う（人流フォルダ内の grid*/ も合わせて読む）

    4. 家電データのフォルダ（任意）:
    kaden_out: kaden_event_ts.csv と kaden_baseline_ts.csv（kaden_compare.ipynb の出力）。郵便番号の点として表示し、ホバーで時系列

    5. 降雨（XRAIN）のフォルダ（任意）:
    xrain_to_geotiff.py の出力（rain_YYYYMMDD_HHMM.tif。index.json は無くてよい）。車流フォルダの中の rain/ でも可。道路の下に半透明で重ねる

    6. SNS 投稿の CSV（任意、複数可）:
    FASTALERT 形式（投稿ID, 日時, 事象区分, …, 緯度, 経度, 投稿文）か、post_id, post_datetime_jst, latitude, longitude, message, source_category … の形式（UTF-8 / cp932）。緯度経度のある投稿を地点に表示し、クリックで本文と投稿リンク
